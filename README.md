# Postman-API-Testing


# 🚀 QA Automation Testing Framework

### Objective

### Project Objective

This project demonstrates API testing skills in **Postman** by performing CRUD operations on book orders using HTTP methods (**GET, POST, PATCH, and DELETE**). The project covers submitting new book orders, retrieving order details and status, updating existing orders, and deleting orders. Additionally, JavaScript test scripts are implemented to validate HTTP response status codes and verify the successful execution of API requests.

---

## 🔍 Scope of Testing

### In Scope
The scope of this project includes testing the Book Orders API using Postman to verify the functionality, reliability, and correctness of API requests.

The following activities are covered:

- **POST:** Submit a new book order.
- **GET:** Retrieve book order details and check order status.
- **PATCH:** Update an existing book order.
- **DELETE:** Delete an existing book order.
- **Status Code Validation:** Verify that API responses return expected HTTP status codes (2xx).
- **Response Validation:** Validate response bodies and ensure returned data matches the expected results.
- **Automated Testing:** Implement JavaScript test scripts in Postman to automate API response validation.**

### Out of Scope

* Performance
* Load testing
* Security testing
* Database testing
---

## Key Concepts & Techniques

- **Postman Variables:** Using variables to store and reuse dynamic values across requests.
- **Collection Runner:** Executing multiple API requests and test cases automatically.
- **Request Execution Order:** Managing the sequence of API requests to ensure proper workflow execution.
- **Newman:** Running Postman collections through the command line.
- **API Authentication:** Handling authentication to access protected API endpoints.
- **Response Data Extraction:** Extracting values from API responses and storing them in variables for use in subsequent requests.
- **Automated Test Scripts:** Writing JavaScript assertions to validate response status codes and response data.
